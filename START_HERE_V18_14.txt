GITHUB / VERCEL
1. Back up your Nifty repository or use a new branch.
2. Extract this ZIP. Upload its contents to the Nifty repository ROOT, alongside main.py and vercel_entry.py. Do not upload the ZIP itself or place the whole project inside an extra subfolder.
3. Preserve your existing deployment settings and private environment variables. The .env.example file contains blank placeholders only.
4. Ensure .github/workflows/nifty-monitor.yml and .github/workflows/test-v1814.yml are in those exact folders.
5. Deploy through your existing Vercel project. This build has not been pushed or deployed automatically.

REQUIRED CONFIGURATION
Vercel environment: DATABASE_URL, JWT_SECRET, NIFTY_MONITOR_SECRET, SIGNAL_EXPORT_KEY. Retain your existing NEWS_API_KEY and optional provider settings.
GitHub Actions secrets: NIFTY_SITE_URL (your HTTPS site URL) and NIFTY_MONITOR_SECRET (same value as on Vercel).
Use privately generated random values for JWT_SECRET, NIFTY_MONITOR_SECRET and SIGNAL_EXPORT_KEY. Do not put real secrets into GitHub files.

The existing PostgreSQL account must be able to create the journal table. Keep existing users and tables; this package does not require deleting data.
