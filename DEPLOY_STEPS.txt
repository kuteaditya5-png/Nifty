NIFTY AI V7 - GIT + VERCEL DEPLOYMENT

1. Extract this ZIP.
2. Open your existing GitHub Nifty repository.
3. Replace the existing app.py with the app.py from this package.
4. Also upload/update the other package files if GitHub does not already have them.
5. Commit directly to main (or merge your branch into main).
6. Vercel should automatically start a new deployment.
7. Confirm NEWS_API_KEY is still configured in:
      Vercel -> Project -> Environment Variables
8. After Status = Ready, test:
      /health
      /prediction
      /fno-alerts
      /option-chain
      /dashboard
      /backtest?period=6mo

BROWSER ALERTS:
Open /dashboard and press 'Enable Browser Alerts'.
Keep the dashboard open for browser-based minute refresh alerts.

The website currently refreshes every 60 seconds.
